# Grão+ — gestão de vendas de café

Aplicação responsiva em React/Vite, com autenticação Supabase, vendas, clientes, estoque, movimentações, financeiro e metas.

## Desenvolvimento
`npm install` e `npm run dev`.

## Build
`npm run build`.

Configure `VITE_SUPABASE_URL` e `VITE_SUPABASE_ANON_KEY` no Vercel. A chave publicável pode ser usada no navegador; nunca publique a `service_role`.
